## Context
Согласовано пользователем: последовательные POST, непустое текстовое подтверждение, GET каталога только после всех неудач.
## Goals / Non-Goals
Goals: остановка после первого непустого текстового ответа; сохранение безопасных результатов.
Non-Goals: замена runtime-моделей, новые retries, live-запросы, deploy.
## Decisions
Обычный async for вместо gather сохраняет порядок без лишних запросов. Успех проверяется через bool(content.strip()) для строкового content. Промт хранится в ai/prompts/model_probe.md и читается через asyncio.to_thread. Лимит ответа 32 токена вместо 4 для русской фразы. Файл отчёта перезаписывается и при успехе, catalog_fetched=false исключает путаницу со старым каталогом. Результат сохраняется как фиксированный маркер text_received или empty, без сырого текста. При ошибке GET сохраняются результаты POST.
## Risks / Trade-offs
Последовательные таймауты увеличивают startup при всех отказах; сохраняется существующий timeout каждой модели. Каталог не гарантирует успешную генерацию. Успех probe не гарантирует успех последующих production-запросов.
