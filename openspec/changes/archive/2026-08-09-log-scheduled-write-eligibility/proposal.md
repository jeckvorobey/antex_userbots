## Why

При запуске swarm не видно, может ли каждый аккаунт отправлять сообщения в целевую группу и какие Telegram-права определили это состояние.

## What Changes

- Логировать для каждого бота и каждой инициализированной группы значение `can_write`.
- Выводить параметры Telegram-прав, по которым вычислено значение: запрет отправки для участника, запрет по умолчанию в группе и статус администратора.

## Capabilities

### New Capabilities

- `startup-write-permission-logging`: Наблюдаемое определение возможности аккаунта отправлять сообщения при инициализации группы.

### Modified Capabilities

- Нет.

## Impact

- `run.py`: проверка прав после получения доступа к группе и стартовое логирование.
- `tests/test_runtime.py`: регрессионный тест лога.
- `README.md`: описание нового стартового лога.
